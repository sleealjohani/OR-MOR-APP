# OR & MOR | أور أند مور — Spatial Café App (prototype)

The café itself is the interface. Instead of tabs and menus, the app opens with a cinematic
fly-through from the street into a 3D recreation of OR & MOR. You tap a real table to reserve or
order, walk up to the cashier for delivery, pickup and catering, and visit the management desk for
feedback and support.

This branch is the **first native iPhone prototype**. It covers the full core interaction:

| Step | What happens |
| --- | --- |
| Logo intro | The crest draws itself in light, fills with gold, then the Arabic name is revealed right-to-left and the Latin name left-to-right. |
| Fly-through | A spline camera path runs from the street, past the lit signage, through the glass doors (which swing open), and settles at the hub view inside. |
| Hub | Glowing rings and floating labels mark the tables, the cashier and management. Drag to look around. |
| Table | The camera approaches, rises and rotates into a **true 90° overhead view** of the marble tabletop with the chairs still visible. A translucent panel offers *Reserve / Order / Celebrate*. |
| Cashier | The camera passes the column and stops facing the counter. You get delivery, pickup, catering, the menu and a call button. |
| Management | Contact, complaint, suggestion, rating, and follow-up on earlier requests. |
| Back | Replays the exact same camera path in reverse. |

There is also a conventional quick-navigation menu (top corner), Arabic RTL / English, reduced
motion (follows the system setting or an in-app toggle), skip / auto-skip of the intro, and a
graphics-quality setting.

## Run it

You need a Mac with Xcode 16 or newer and an iPhone (or the simulator) on iOS 18+.

```bash
brew install xcodegen      # once
xcodegen generate          # creates ORMOR.xcodeproj from project.yml
open ORMOR.xcodeproj
```

In Xcode, select the **ORMOR** target → *Signing & Capabilities* → choose your Team. Then run on
your iPhone. Use a real device to judge motion and lighting; the simulator renders RealityKit, but
more slowly.

Every push runs the build and unit tests on GitHub's macOS runners
(`.github/workflows/ios.yml`).

## Project layout

```

  App/        RootView (scene + overlays + flow), Settings, app entry
  Camera/     CameraPath (reversible Hermite splines, easing), CameraDirector (moves, back stack)
  Scene/      CafeLayout (positions, camera poses), CafeSceneBuilder (3D stand-in), CafeSceneView (RealityKit ↔ SwiftUI)
  Brand/      Vector logo data + parser, LogoIntroView
  Design/     Brand colours, fonts, glass panels, settings / language
  Features/   Table, Cashier, Management panels; shared ordering and form components
  Data/       Models and the CafeService protocol (mock now, Supabase later)
  Resources/  Asset catalog (textures from the café photos, logo, app icon), OFL fonts
ORMORTests/   Camera path and navigation tests
tools/        gen_assets.py — regenerates textures and logo data from the brand kit and photos
docs/         Reference photos, 3D pipeline notes
```

## What is real and what is a placeholder

* **3D café**: a lightweight stand-in built from primitives, laid out from the photos and textured
  with them (real tabletop veining, pastry display, coffee bar, wall art). It exists to validate camera
  motion and interaction. Replacing it with a scanned model is the next big step; see
  [docs/3D-PIPELINE.md](docs/3D-PIPELINE.md).
* **Logo**: the brand kit's reconstructed vector, traced from a photo of the cup. Swap in the official
  vector when available. The data is regenerated by `tools/gen_assets.py`.
* **Colours**: the UI uses the brand kit's measured gold `#836117` on ivory, and the brief's
  `#D6A84B` as the "glow" gold for signage and highlights. Neither is an official brand code yet.
* **Fonts**: interim OFL fonts from the brand kit (Reem Kufi, Noto Sans Arabic, Noto Serif).
* **Data**: menu, availability, reservations, orders and support tickets come from
  `MockCafeService`. Prices are placeholders. Payments are not connected. `CafeInfo.phone` is a
  placeholder number.

## Next steps
